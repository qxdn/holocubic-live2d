## 语音对话

当前只有文字流式聊天，尚未接入录音、语音识别、语音合成与音频播放。以下优先级表示语音模块内部的推进顺序。

### P0：完成基础语音链路

- [ ] 麦克风录音：提供按住说话入口，处理权限、开始与结束录音、取消录音及设备不可用。
- [ ] 语音识别（ASR）：将录音转为文字，展示识别状态与错误，支持重试，将识别结果接入现有聊天。
- [ ] 语音合成（TTS）：将助手正文转为语音，确定中文支持、角色音色及服务配置。
- [ ] 音频播放：管理播放队列、停止播放和失败反馈，避免重复朗读。
- [ ] 统一对话状态：管理“录音中 → 识别中 → 思考中 → 播放中”的切换，避免录音与播放冲突。
- [ ] 验收基础链路：按住说话 → 转文字 → 现有聊天 → 完整回复转语音 → 播放。

### P1：减少等待并联动角色

- [ ] 按句流式播报：分句合成并按顺序播放，只朗读助手正文，不朗读 reasoning、工具参数或工具结果。
- [ ] 打断与取消：用户停止或开启新对话时，取消生成、合成和播放，清空旧音频队列；迟到的结果不得恢复旧播放。
- [ ] 口型同步：根据播放音频驱动角色口型，播放结束、失败或打断后复位，并协调动作与说话状态。
- [ ] 验收流式播报与打断：连续分句播放无重复、无乱序，打断后无残留语音，角色口型正确复位。

### P2：连续对话与运行观测

- [ ] 连续对话：检测说话开始和结束、处理静音超时，防止角色播放的声音被再次识别；验收免按键对话。
- [ ] 语音耗时观测：记录识别耗时、模型首字耗时、合成首段耗时和开始播放时间，关联同一轮对话以定位延迟。

建议先完成 P0 基础链路，再加入按句播报、打断与口型同步，最后实现免按键连续对话。
